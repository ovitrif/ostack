# ostack

Reusable agent skills following the [Agent Skills standard](https://agentskills.io/specification).

## Install

Install with a compatible skills manager:

```bash
npx skills add ovitrif/ostack -g
```

Or copy a directory from `skills/` into your agent's skills directory.

## Skills

| Skill | Purpose |
| - | - |
| [bro](skills/bro/README.md) | Rewrite a bloated reply or any text into the shortest factual version: result first, bullets, no filler, every fact kept. |
| [claude-switch](skills/claude-switch/README.md) | Switch Claude Code and the Claude desktop app between accounts while preserving local sessions, sidebar groups, routines and settings. |
