# Public skills

Publish generic functionality and synthetic examples. Keep personal account details, operating habits, private instructions and local configuration outside this repository. Review prose and fixtures as well as code before publication.

Each skill is the sole implementation. Read optional machine-local settings from `${XDG_CONFIG_HOME:-~/.config}/ostack/<skill>/` and runtime state from `${XDG_STATE_HOME:-~/.local/state}/ostack/<skill>/`. Never import private companion files into this repository.
